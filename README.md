# Pet Store
### Описание:
Это проект для проработки автоматизации тестирования API сервиса в рамках обучения автоматизации тестирования API. 
В проекте реализован небольшой API клиент, на основе которого выполняются тесты.

#### Цель:
Автоматизация end-to-end сценария жизненного цикла сущности в stateful API (Swagger Petstore  — публичный API с состоянием, который хранит объекты в памяти в течение сессии).
Задание моделирует типовую производственную ситуацию: нужно проверить не отдельный эндпоинт, а связный бизнес-сценарий — создание объекта, чтение, обновление, повторное чтение и удаление с проверкой, что после удаления объект недоступен. 
Это отражает реальную работу Automation QA, где дефекты чаще проявляются на стыке операций, а не внутри одного запроса.

#### Критерии приемки:
* Сценарий воспроизводим: запускается повторно, не зависит от порядка тестов и не оставляет «мусорных» записей в общем сервисе.
* Решение обосновано, а не собрано по шаблону: в комментариях зафиксировано, почему выбран такой уровень изоляции и на какое поведение API можно опираться.
* Тест проверяет риски, а не строки кода: ловит рассогласование состояния между операциями, потерю обновлений и «фантомные» объекты после удаления.

### Стэк/требования:

* pytest 9.1.1 
* requests 2.34.2
